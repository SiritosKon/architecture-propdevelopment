# architecture-propdevelopment

Проектная работа 5 спринта — аудит безопасности данных компании PropDevelopment.

- **Task1** — проверочный лист по безопасности данных (mindmap, draw.io)
- **Task2** — проверочный лист для бизнес-систем (Markdown)
- **Task3** — внешние интеграции: диаграмма контекста, диаграмма контейнеров, требования
- **Task4** — ролевой доступ к Kubernetes (RBAC): таблица ролей + скрипты
- **Task5** — управление трафиком внутри кластера (NetworkPolicy)
