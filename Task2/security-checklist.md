# Проверочный лист безопасности бизнес-систем PropDevelopment

| Проверяемый пункт | Ответ | Комментарий |
|---|:---:|---|
| Проверяются ли права на уровне объекта (клиент видит только свои данные)? | Нет | В ЛК видно ФИО другого клиента — устранить IDOR/BOLA |
| Изолированы ли данные разных управляющих компаний (мультитенантность)? | Нет | Партнёр одной УК видит данные другой |
| Централизовано ли управление идентификацией (единый IdM)? | Нет | Несколько несогласованных точек регистрации |
| Реализована ли ролевая модель доступа (RBAC, минимальные привилегии)? | Нет | Для Kubernetes завести ролевую модель — Task 4 |
| Применяется ли многофакторная аутентификация (MFA)? | Нет данных | Для привилегированного и внешнего доступа |
| Есть ли требования к сложности и обновлению паролей? | Нет данных | — |
| Проводится ли аудит привилегированных учёток и деактивация уволенных? | Нет данных | — |
| Реализована ли защита мобильного приложения собственников как внешнего канала доступа (аутентификация, сессии, защита устройства)? | Нет данных | Внешний канал, управляет умным домом и замком квартиры — отдельная поверхность атаки, защита в кейсе не описана |
| Есть ли политика классификации данных, соответствует ли 152-ФЗ? | Частично | Классификация — Task 1, в системах не закреплена |
| Минимизируется ли объём ПДн в формах и контрактах API? | Нет | Контракты API отдают избыточные ПДн |
| Контролируется ли передача ПДн третьим лицам (партнёры, госорганы)? | Нет | Передача без реестра и оснований |
| Выполняется ли резервное копирование всех БД? | Да | «Для всех баз данных выполняется резервное копирование на глубину, необходимую для восстановления» |
| Зашифрованы ли резервные копии? | Нет данных | В кейсе про шифрование копий не сказано |
| Есть ли межсетевой экран (firewall) для внешнего доступа? | Да | «Доступ для внешних пользователей осуществляется через межсетевой экран» |
| Сегментирована ли внутренняя сеть на зоны? | Нет | Сегментацию внутри кластера настраиваем в Task 5 |
| Изолирован ли трафик партнёрских интеграций? | Нет | Единых политик для партнёров нет |
| Информируется ли специалист по ИБ обо всех значимых изменениях? | Нет | Обмен информацией между командами нарушен |
| Хранятся ли ПДн граждан РФ на территории РФ (локализация)? | Нет | Часть мощностей арендуется у облачного провайдера |
